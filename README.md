# Reflection

Reflection (reflection.com.ng) is a technology company focused on tech career coaching, EdTech, online advertising and software development. This repository is the company website, which presents its services, its academy and its team.

## Business idea

Reflection helps brands and people succeed in tech through two lines of business:

- **Reflection Academy** — training and career coaching for people who want to enter tech, with tracks in:
  - frontend development
  - backend development
  - mobile app development
  - UI/UX design
  - graphic design
  - motion design
- **Agency services** — a team of brand identity designers, graphic designers, UI/UX designers and mobile, web and desktop developers who build brands and software for clients.

The website turns visitors into academy students and agency clients.

## Key features

- Home page with banner, about section, team and blog highlights
- Academy page and a page for each training track
- About and contact pages, with Google Maps
- Smooth reveal animations and carousels
- Responsive layout with React Bootstrap

## Tech stack

- React (Create React App)
- React Router
- React Bootstrap and Bootstrap
- Font Awesome icons
- react-reveal animations, react-elastic-carousel
- Google Map React

## Getting started

```bash
npm install
npm start        # http://localhost:3000
npm run build
```
